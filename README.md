# 🛍️ Frontend – Tienda Online (Angular)

Frontend de una **tienda online (e-commerce)** desarrollado con **Angular 20**, diseñado para consumir una API REST y ofrecer una experiencia de usuario moderna, rápida y responsiva.

---

## 🛠️ Tecnologías utilizadas

- **Angular 20**
- **TypeScript**
- **Angular Material**
- **RxJS**
- **HTML5 / SCSS**
- **Angular Router**
- **HTTP Client**
- **JWT Authentication**
- **Node.js / NPM**
- **Angular Material**

---

## 📋 Requisitos previos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

- **Node.js** >= 18
- **NPM** >= 9
- **Angular CLI** >= 20
- Navegador web moderno (Chrome, Edge, Firefox)

Verificar versiones:
```bash
node -v
npm -v
ng version
